<p>适用于树莓派RJ45口连接网线，使用树莓派自带的无线网卡开启AP的情况</p>

<h2 id="heading-0" data-id="heading-0">前置</h2>
<p>用网线连接树莓派的RJ45网口，可以使用DHCP自动分配的IP或者设置静态IP</p>
<h2 id="heading-1" data-id="heading-1">系统配置</h2>
<h3 id="heading-2" data-id="heading-2">设置IP转发</h3>
<p>因为Linux系统默认关闭了IP转发，所以要手动开启，编辑<code>/etc/sysctl.conf</code>，取消下列行的注释：</p>
<pre><code class="hljs language-ini"><code class="hljs language-ini" data-raw="net.ipv4.ip_forward%3D1"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content"><span class="hljs-attr">net.ipv4.ip_forward</span>=<span class="hljs-number">1</span></span>
          </div></code>
</code></pre><p>然后应用配置：</p>
<pre><code class="hljs language-bash"><code class="hljs language-bash" data-raw="sudo%20sysctl%20-p"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> sysctl -p</span>
          </div></code>
</code></pre><h3 id="heading-3" data-id="heading-3">设置有线接口的NAT</h3>
<p>如果连接网线的接口为<code>eth0</code>，设置</p>
<pre><code class="hljs language-bash"><code class="hljs language-bash" data-raw="sudo%20iptables%20-t%20nat%20-A%20POSTROUTING%20-o%20eth0%20-j%20MASQUERADE%0Asudo%20iptables%20-A%20FORWARD%20-i%20wlan0%20-o%20eth0%20-j%20ACCEPT%0Asudo%20iptables%20-A%20FORWARD%20-i%20eth0%20-o%20wlan0%20-m%20state%20--state%20RELATED%2CESTABLISHED%20-j%20ACCEPT"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE</span>
          </div><div class="code-row">
            <span class="line-num" data-num="2"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT</span>
          </div><div class="code-row">
            <span class="line-num" data-num="3"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT</span>
          </div></code>
</code></pre><p><em>如果提示找不到命令iptables，先执行<code>sudo apt install iptables</code></em></p>
<p>设置后，每次树莓派重启就会重置NAT配置，因此需要持久化设置，通过安装<code>iptables-persistent</code>来保存规则：</p>
<pre><code class="hljs language-bash"><code class="hljs language-bash" data-raw="sudo%20apt%20install%20iptables-persistent%0Asudo%20netfilter-persistent%20save"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> apt install iptables-persistent</span>
          </div><div class="code-row">
            <span class="line-num" data-num="2"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> netfilter-persistent save</span>
          </div></code>
</code></pre><p>之后再次重启<code>dnsmasq</code>：</p>
<pre><code class="hljs language-bash"><code class="hljs language-bash" data-raw="sudo%20systemctl%20restart%20dnsmasq"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content"><span class="hljs-built_in">sudo</span> systemctl restart dnsmasq</span>
          </div></code>
</code></pre><h3 id="heading-4" data-id="heading-4">网络配置</h3>
<p>如果树莓派使用的网络管理工具是<code>systemd-networkd</code>，先查看其状态</p>
<pre><code class="hljs language-bash"><code class="hljs language-bash" data-raw="sudo%20systemctl%20status%20systemd-networkd"><div class="code-row">

<h2 id="heading-11" data-id="heading-11">总结</h2>
<p>树莓派由于硬件限制，无线网卡在2.4GHz情况下热点的速率大概只有70Mb/s左右，开启5GHz信号和设置VHT为80MHz的情况下，Windows显示的连接速度为150Mb/s，从连接速度来看翻了一倍，使用<a href="https://test.ustc.edu.cn/">中国科学技术大学测速网站</a>测试下载速度，原通过<code>nmcli</code>使用2.4GHz信号开启的热点下载速度大约为12Mb/s，改用5GHz后能跑到100多Mb/s，效果提升还是很明显。理论上树莓派4B的无线网卡能跑到千兆速度，<del>但实在是优化不来</del>。采用openWrt配置无线热点因为树莓派性能过于鸡肋，内存和CPU经常吃满卡死，只能采用这种折中的办法。<strong>有条件还是得整一个正儿八经的路由器</strong><del><sub>或者Mac mini</sub></del></p>
