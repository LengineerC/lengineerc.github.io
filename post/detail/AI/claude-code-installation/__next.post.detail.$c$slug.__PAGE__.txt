          </div></code>
</code></pre><p>就只需要填写</p>
<pre><code class="hljs language-plaintext"><code class="hljs language-plaintext" data-raw="https%3A%2F%2Fapi.xxx.com"><div class="code-row">
            <span class="line-num" data-num="1"></span>
            <span class="code-content">https://api.xxx.com</span>
          </div></code>
</code></pre><p>模型映射填写你使用的中转站支持的模型名称即可，不一定非要claude，其他的如gpt之类的也行。</p>
